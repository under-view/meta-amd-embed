# meta-amd-embed

BSP layer designed specifically for AMD processors.

## Dependencies

* URI: https://git.openembedded.org/openembedded-core
    * branch: master
    * revision: HEAD
* URI: https://git.openembedded.org/bitbake
    * branch: master
    * revision: HEAD

## Build

```bash
$ bitbake-layers add-layer ../meta-amd-embed
```
